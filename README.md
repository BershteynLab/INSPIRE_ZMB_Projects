## Major Updates

### 2026-06-11

INSPIRE project: cost effectiveness interventions updated:

* ZAIMARA
  * How: CARF reduction
  * What: 30% (10-43%) reduction per coital act, for a duration of 3 (1-5) years
  * Who: 40% of unmarried, HIV-negative AGYW ages 15-19
  * When: starting 2025-2050
* ART Retention Intervention
  * How: return all individuals to ART who drop out, triggers upon HCTUptakePostDebut8, which may happen when someone undergoes dropout (OnART3)
  * What: defaulter tracing
  * Who: all AYA
  * When: starting 2025-2050
* PrEP
  * How: distribute prep using RefTracker
  * What: 3 (1-12) months of oral PrEP use following initiation; 75% (55-90%) protective efficacy (citing Baeten)
  * Who: all VOICE criteria eligible for receiving PrEP
  * When: 2025-2050
